# HR-Dashboard
Employee Attrition Analysis Dashboard
This Power BI HR analytics dashboard provides a comprehensive analysis of workforce turnover across 1,500 employees, identifying key retention patterns across departments, job satisfaction levels, compensation, and geographic regions. Featuring an overall attrition rate of 15.07% (226 exits), the interactive visual insights highlight critical turnover drivers—such as higher departure volume among lower-tenured staff and specific satisfaction cohorts, along with department-specific departure reasons ranging from pay and growth opportunities to management and work environment factors. By integrating relational data across employee demographics, fact-based attrition logs, and time-intelligence tracking, this repository equips HR leaders with actionable metrics to optimize talent retention strategies and reduce organizational turnover.
